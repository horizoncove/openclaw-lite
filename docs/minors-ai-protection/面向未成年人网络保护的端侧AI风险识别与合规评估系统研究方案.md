# 面向未成年人网络保护的端侧 AI 风险识别与合规评估系统研究方案

## 一、项目名称

```text
面向未成年人网络保护的端侧 AI 风险识别与合规评估系统研究
```

可选简称：

```text
未成年人网络安全保护边缘智能系统
```

## 二、项目背景

未成年人在网络空间中的社交、娱乐、学习和内容消费频率不断提升，随之产生了隐私泄露、陌生人诱导、网络欺凌、线下见面诱导、情感操控、非法内容传播等风险。

现有平台治理主要依赖云端审核和事后处置，存在以下问题：

```text
响应滞后
隐私暴露
缺少多轮对话风险识别
缺少端侧即时拦截
缺少法治场景化评估标准
缺少可解释合规闭环
```

因此，有必要研究一种面向未成年人网络保护的端侧 AI 风险识别系统，在本地设备上完成风险初筛、分级、提醒和阻断，并结合 AI 治理与合规评估体系，形成“技术保护 + 法治治理”的综合方案。

## 三、研究目标

本项目拟围绕未成年人网络安全保护，构建一套端侧风险识别与合规评估系统。

核心目标：

```text
1. 建立未成年人网络风险场景库
2. 建立风险标签体系和风险分级标准
3. 构建端侧文本风险分类模型
4. 构建图片隐私风险检测模型
5. 构建多轮对话风险识别机制
6. 构建风险分级规则引擎
7. 构建合规评估和脱敏审计体系
8. 开发可演示的端侧原型系统
```

## 四、研究内容

### 4.1 未成年人网络风险场景体系研究

梳理未成年人网络空间中的典型风险场景，包括：

```text
陌生人搭讪
年龄试探
隐私索取
照片诱导
线下见面诱导
礼物交换诱导
网络欺凌
情感操控
胁迫威胁
个人信息泄露
平台治理失效
```

形成：

```text
风险场景分类表
风险标签体系
典型案例库
合成样本模板
评估题库
```

### 4.2 风险标签和分级标准研究

建立多级风险体系：


| 等级 | 名称     | 处置方式        |
| ---- | -------- | --------------- |
| S0   | 正常     | 允许            |
| S1   | 可疑     | 提醒            |
| S2   | 高风险   | 阻止            |
| S3   | 严重风险 | 人工复核 / 告警 |
| S4   | 强制处置 | 合规流程        |

建立文本、图片和多轮对话标签：

```text
age_probe
privacy_request
photo_request
school_request
contact_request
offline_meeting
gift_exchange
emotional_manipulation
coercion
threat
grooming_sequence
help_request
```

### 4.3 端侧文本风险分类模型研究

研究适合边缘设备部署的小型文本分类模型。

候选模型：

```text
MiniLM
DistilBERT
TinyBERT
MacBERT-small
小参数中文分类模型
```

目标：

```text
模型小型化
本地推理
低延迟
高风险高召回
可解释输出
```

### 4.4 图片隐私风险检测研究

研究图片上传场景中的隐私泄露和高风险内容检测。

检测方向：

```text
身份证件
学校信息
联系方式
地理位置
聊天截图
自拍风险
OCR 隐私信息
```

候选模型：

```text
MobileNetV3
EfficientNet-lite
MobileViT
TinyViT
OCR + 规则检测
```

### 4.5 多轮对话风险识别研究

研究多轮渐进式风险识别，尤其是 grooming 风险链路。

典型链路：

```text
普通聊天 -> 年龄试探 -> 隐私索取 -> 照片诱导
陪伴安慰 -> 情感依赖 -> 操控 -> 线下见面
礼物承诺 -> 交换照片 -> 保密要求
```

研究内容：

```text
上下文窗口建模
风险升级路径识别
多轮对话标签体系
风险趋势评分
```

### 4.6 端侧多模态融合研究

融合多种风险信号：

```text
文本风险分数
图片风险分数
OCR 风险分数
对话历史风险
用户关系特征
行为频次特征
```

输出：

```text
综合风险等级
建议处置动作
可解释风险原因
```

### 4.7 AI 治理与合规评估体系研究

从法治角度研究系统边界：

```text
数据最小化
未成年人个人信息保护
敏感数据脱敏
高风险事件处置
平台责任边界
监护人告警机制
人工复核机制
算法可解释性
模型误判责任
```

形成：

```text
合规评估指标体系
数据处理规范
平台责任建议
伦理审查建议
政策建议报告
```

## 六、数据方案

项目坚持安全合规的数据原则。

允许使用：

```text
人工合成数据
LLM 辅助生成并人工审核的数据
公开安全研究数据集
授权脱敏案例
合成图片和安全替代图片
```

禁止使用：

```text
真实未成年人私密数据
违法材料
泄露数据
未授权平台数据
可识别身份的敏感原始内容
```

MVP 数据规模建议：


| 数据类型       |        数量 |
| -------------- | ----------: |
| 文本单句样本   |     3000 条 |
| 多轮对话样本   |      500 组 |
| 图片样本       |     1000 张 |
| 拒绝和保护文案 |      500 条 |
| 评估集         | 500-1000 条 |

## 十四、总结

本项目是一项“法学 + 人工智能 + 未成年人保护 + 数据合规”的交叉研究。

核心价值：

```text
以端侧 AI 提升未成年人网络风险识别能力
以法治研究明确平台责任和合规边界
以隐私保护降低数据使用风险
以原型系统推动可验证的社会治理创新
```

项目最终目标是形成一套：

```text

可审计

可试点推广
```

的未成年人网络安全保护边缘智能系统。
