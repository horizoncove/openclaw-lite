# 数据合规规范 v1（P1）

状态：生效（随 p0-v1.0 人类签字启动）  
适用范围：本项目全部训练/评测/演示文本数据生产  
上位依据：`p0/runtime_redlines.md`、研究方案数据红线章节

---

## 1. 允许的数据来源

| 来源 | 是否允许 | 条件 |
|---|---|---|
| 人工/模板合成中文样本 | ✓ | 须符合标签定义，禁止性化描写 |
| 基于 P0 examples/golden 的改写扩写 | ✓ | 改写后仍不得引入真实私密信息 |
| LLM 辅助改写（可选） | ✓ | 输出必须人工或规则复核；prompt 不得粘贴真实私密 |
| 公开安全研究许可语料 | 有条件 | 须写入 Data Card；许可证允许；去标识 |
| 真实未成年私密聊天 | ✗ | **一律禁止**，含“授权脱敏原文”捷径 |
| 未授权平台抓取 | ✗ | 禁止 |
| 成人业务线语料 | ✗ | 物理/流程隔离 |

---

## 2. 内容禁区

```text
✗ 任何儿童性化、色情描写或性剥削内容
✗ 真实姓名+学校+住址等可识别组合（合成也避免逼真门牌）
✗ 可执行的伤害教唆细节
✗ 为“对抗未成年人保护系统”而设计的绕过教程（红队种子另册管理，且仅内部）
```

合成策略：用**类型化、可教学的风险话术**，不用真实受害者叙事。

---

## 3. 存储与审计字段

- 训练/评测集可存合成 `text`（本阶段必要）  
- 运行时审计包：**不得存原文**，仅 `sha256` + 标签 + 等级 + 模型版本（见 P0/P3）  
- 每条样本必须有：`source`、`review_status`、`annotator`、`ts`  
- 数据集版本目录不可原地覆写；升版用 `v0.2/` 等

---

## 4. 标注与质检

1. 标注员须先通过 P0 金标测验（宏 F1 ≥ 0.85）  
2. 每 100 条抽 10 条双人复标；争议写 `decisions.md`  
3. 抽检正确率门槛 ≥ 95%  
4. `needs_review` 不得进入 test 金标冻结集，除非 Owner 终裁

---

## 5. 划分与泄漏防制

```text
1) 规范化：去首尾空白、全角半角统一、连续空白折叠
2) 同一规范化文本只能出现在一个 split
3) P0 golden 优先进入 test（或独立 golden 引用），不得进 train
4) 对抗集 adv 从 test 风格改写，不得回灌 train
```

---

## 6. 对外表述

- 可说：“训练与评测使用合成数据，未使用真实未成年私密聊天”  
- 不可说：“已满足全部数据合规法定义务 / 已通过某监管认证”（除非另有证书）  
- `law_mapping.csv` 仍为草案辅助，不单独构成合规证明

---

## 7. 违规处置

| 级别 | 情形 | 动作 |
|---|---|---|
| P0 | 混入真实未成年私密原文 | 立即隔离目录、删除原文、事故记录、暂停发布 |
| P1 | 标签体系被擅自改 key | 回滚并升 decisions |
| P2 | 抽检 <95% | 冻结升版，返工 |
