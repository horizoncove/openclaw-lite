## 2) 一句话结论

当前 adv 与 train 同属「模板 + `stylize` 盐值」流水线，对抗变换几乎只有插空格/极少数近形替换，**达不到最小对抗回归门禁**；去盐后意图骨架与 train 高度同质，盐值标记还会污染评测有效性。

## 5) 深度审查发现

### 5.1 生成路径（实读代码）

`synthesize_batch.py` 关键路径：

1. `build_pool()`：`TEMPLATES` 填槽 → `stylize(..., salt=...)` **必打盐值标签**；  
2. `assign_ids_and_split()`：从 remaining 的 `template|paraphrase|seed_p0` 切 `adv_budget` 条；  
3. `adversarial(text)`：**仅**插空格 + 三组替换 + 可选「哈」；  
4. 跨 split 去重用 `normalize()`（去空白、统一标点），**不去盐、不抽骨架**。

因此：adv 与 train 共享同一模板词表、同一前后缀/软化词/称呼池；所谓「对抗」几乎不改变意图字符串。

### 5.2 同质化量化（v0.3 实算）

| 指标 | 结果 | 解读 |
|---|---|---|
| adv 条数 / 标签覆盖 | 500；8 标签均有（51–72） | 数量达标，多样性不足 |
| 精确 `normalize` 泄漏进 train | **0** | validator 意义下的泄漏 PASS |
| strip-salt 后与 train 撞车 | **30/500（6%）** | 盐值掩盖近重复 |
| 去盐+去装饰后骨架∈train | **381/500（76.2%）** | **严重同质** |
| vs 2k train 的 max 3-gram Jaccard | 中位 ≈0.45；≥0.5 ≈41.6% | 表面改写、内核相同 |
| adv 多标签 / 多句 | **0 / 0** | 无慢诱导、无递进 |
| 核心 `adversarial()` 痕迹（空格/`V信`/`电 话`/尾「哈」） | ≈328/500（65.6%） | 其余几乎只靠盐值与软化词「扮对抗」 |

### 5.3 对抗策略覆盖是否过薄

| 策略 | 承诺（pipeline/data_card） | 实测 | 判定 |
|---|---|---|---|
| 空格插入 | 有 | 253/500；且 **41** 条把空格插进盐值数字（如 `5500 284`），像噪声不像真实对抗 | 有量、质差 |
| 谐音/近形 | 有 | `V信` 4；`电 话` 6；`威信` 2（train 已有 170 条「威信」来自 paraphrase）；`薇信`/`加v` 等 ≈0 | **过薄** |
| 委婉/间接 | 有 | 主要靠与 train 共用的 `SOFTENERS`（207 条），无额外委婉句式 | **过薄（且非 adv 独有）** |
| 慢诱导 | data_card 已自承偏少 | 慢诱导关键词 0；多句 0；伪多轮 0 | **缺失** |

结论：对「只会正则/关键词」的基线，插空格与 `V信` 或许可回归；对 P2 分类器，**当前 adv 高估鲁棒性**。

### 5.4 模板指纹对评测有效性的影响

1. **盐值是强指纹**：8 个固定句式 + 大整数，人眼与模型均极易识别；真实线上诱导不会出现 `别敷衍6502374号问题`。  
2. **train/adv 同构指纹**：双方都盐化 → 指标可能测的是「带盐模板泛化」，不是「对抗鲁棒」。  
3. **可被绕过的评测叙事**：  
   - 攻击方去掉盐值与软化词后，语句与 train 同分布，adv「攻击」失效；  
   - 防守方若过拟合盐值模式，线上无盐样本会失效，而 adv 仍「看起来很好」。  
4. **空格打散盐值**（41 例）制造虚假 OOD，进一步扭曲对抗含义。  
5. 其它词表指纹：`PREFIXES`/`SOFTENERS`/`VOCATIVES` 在 adv 中约 **64.6%** 可检出，与 train 同源，放大同质化。

**评测有效性结论**：在去盐与独立对抗种子完成前，**不得将 adv 准确率/召回作为 P2 对抗门禁或发布 blocker 的唯一依据**。
