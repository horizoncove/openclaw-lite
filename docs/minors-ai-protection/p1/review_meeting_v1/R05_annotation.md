## 6) 分层抽检设计与正确率

### 6.1 抽样（按 spot_check_plan 精神压缩执行）

正式 plan 目标 ≈288；本席独立质检配额 **≥40**，实际 **48**，种子 `20260808`：

| 桶 | 条数 | 说明 |
|---|---:|---|
| train 每标签正例 | 16 | 8 标签 × 2 |
| hard_negative | 8 | train 6 + test 2 |
| normal S0 | 4 | 防误标 |
| combo | 8 | train 5 + test 3 |
| test 非 golden 正例 | 6 | 跨标签 |
| adv | 6 | 对抗可标注性 |
| **合计** | **48** | |

判据对齐 `annotation_guide.md` / `labels.md` / `severity.yaml`：**标签错或等级 ±0 档不符即算错**；多标签漏标高危算错。

### 6.2 正确率估计

| 口径 | 结果 |
|---|---|
| 综合（标签+等级） | **46/48 = 95.8%** |
| 仅标签 | **48/48 = 100%** |
| 仅等级 | **46/48 = 95.8%** |
| 红线违规 | **0** |

> 综合正确率卡在门禁线（≥95%）边缘；**标签质量明显好于等级质量**。结合 offline 全量审计，真实等级噪声高于本批点估计，故不能凭 95.8% 主张“已可冻结”。

### 6.3 主要错误模式

1. **U03 假阳性（over-S3）**：`level_for` 用子串 `"点"` →「吃点东西」变 S3。  
2. **U03 假阴性（under-S2）**：含「你家 / 上门 / 接你」但未命中合成词表 → 仍 S2。  
3. **升级规则实现不完整**：相对 yaml，U05–U09 / 接送升 S3 未完整编码；combo 多数“看起来对”，但原因码与规则不可审计。  
4. **过程风险**：`auto` 占绝对多数，等于把规则生成结果直接当金标用。  
5. **同质化噪声**：编号填充物占比高，不直接导致标签错，但抬高人工抽检成本、污染特征。

## 7) hard_negative / combo / auto 专项评估

### 7.1 hard_negative

| 观察 | 证据 |
|---|---|
| 量 | train 244；test 53；相对 3 万规模偏少 |
| 质量（本批 8 条） | 全部 `labels=[] / S0` 判断正确：安全教育反面教材、平台内好友、应用商店年龄合规、表情包、科普年龄划分、作业求助等 |
| 风险 | ① 覆盖窄，易混边界未饱和；② 部分 HN 仍带诱导腔称呼（宝贝/小朋友）+ 噪声编号，依赖标注员细心；③ `spot_checked` 过度集中在 HN，造成“已抽检”幻觉 |

**结论**：方向正确，**不足以单独支撑误拦控制**；须扩量 + 纳入正式抽检桶。

### 7.2 combo

| 观察 | 证据 |
|---|---|
| 量 | train 875 / test 511 |
| 本批 8 条标签 | 全部多标签命中正确（age+contact、school+offline+接你、emo+contact、photo+privacy 等） |
| 等级 | 7/8 符合升级直觉；`TE05703`（privacy+offline+上门/家）标 S2，按 U03 应为 S3 |
| 原因码 | 0 条含 `R_COMBO_ESCALATE`（统计 train combo 全库） |

**结论**：共现标签教学价值高；**等级/原因码纪律弱于标签**，修 A-B2/A-O2 前不宜当等级金标。

### 7.3 `review_status=auto`

| split | auto | spot_checked | needs_review |
|---|---:|---:|---:|
| train | 29931 | 69 | 0 |
| dev | 12195 | 16 | 0 |
| test | 15387 | 71 | 0 |
| adv | 499 | 1 | 0 |

- `wrap()` 默认写死 `"review_status": "auto"`（`synthesize_batch.py`）。  
- 现存 `spot_checked` 主要来自种子导入，**不是** plan 意义上的分层人工抽检。  
- `needs_review` 全库为 0，与手册“拿不准标 needs_review”相悖——生成管线从未表达不确定度。

**结论**：这是冻结前的 **过程阻断项（A-B1）**，不是文案问题。

## 10) 建议冻结条件（质检视角）
