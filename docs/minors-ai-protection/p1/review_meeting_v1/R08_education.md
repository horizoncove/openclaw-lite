## 2) 一句话结论

训练侧 S0/校园闲聊与 `school_request` 边界总体守住了同伴学业社交空间，且同学问年级已按 P0 统一落为 S1；但拒绝话术库把大量 S1（含年龄/年级）写成“拦截/阻止”，并以“真正的朋友/监护人关注”道德化同伴寒暄，冻结产品文案前必须修正，否则会把软提醒挤成恐吓式过拦。

## 3) 阻断项（FIX）

| ID | 严重级别 | 问题 | 可执行 FIX（路径） |
|---|---|---|---|

结论：

1. **同学问年级**：数据层遵守 P0「统一 S1」；教育关切转移到**处置动作与话术**（见 EDU-B1/B2）。  
2. **学校信息**：索取校名/校门/路线/班级 → S2；纯学业/无定位校园闲聊 → S0；抽样边界清晰。  
3. **风险**：S0 与 age 正例共享「小朋友/宝贝」等称呼槽，可能让模型学偏；属 EDU-O3。

### 6.4 拒绝话术 — 未见羞辱辱骂，但存在恐吓式过拦与道德绑架

| id | level | text | 教育判断 |
|---|---|---|---|
| `RF0001` | S1 | “对方在询问你的年龄或年级。如感到不适，可以不回答…” | **合格**：冷静、可执行、不羞辱 |
| `RF0002` | S1 | “你有权拒绝，不必证明什么” | **合格**：赋权 |
| `RF0018` | S1 | “已为你拦截疑似索取年龄与年级的内容” | **不合格**：S1 不应拦截 |
| `RF0080` | S1 | “涉及年龄与年级的内容已被限制发送” | **不合格**：同上 |
| `RF0041` | S1 | “真正的朋友不会强迫你提供年龄与年级” | **不合格（同伴场景）**：把同学寒暄道德化为“非真朋友”，易羞辱 |
| `RF0077` | S1 | “监护人提示模板：孩子可能被问及年龄与年级” | **不宜默认挂儿童 S1**：同学问年级即扰监护人=过度监控 |
| `RF0036` | S1 | “若感到压力，立刻停止对话，尤其涉及年龄与年级时” | **过激**：首次 S1 应可继续；“立刻停止”留给升级场景 |
| `RF0005` | S2 | “已阻止可能泄露学校或放学路线等信息的内容” | S2 阻止可接受；语气尚冷静 |

全库拒绝话术检索：无「羞辱/笨蛋/活该/变态/报警/违法犯罪」等辱骂或恐吓词。  
问题主因是 **动作等级错位** 与 **同伴场景文案过重**，不是辱骂式内容。

量化（refusal=500）：S1 含拦截/阻止措辞 ≈17；「真正的朋友」框架 ≈25；S1 监护人模板 ≈3；S1 中偏赋权柔和句仅约 5 条——儿童友好软提醒占比过低。

## 7) 教育守护专项意见

### 7.1 是否保住同伴正常交往空间？

| 维度 | 判定 |
|---|---|
| 学业/兴趣 S0 是否充足 | **是**（量上达标，质上偏同质） |
| 纯学业是否被打成 school_request | **未见** |
| 同学问年级是否被标成 S2/S3 | **未见**（纯 age_probe 均为 S1） |
| 产品话术是否会把 S1 变成实质过拦 | **会（当前 refusal 库）→ 必须改** |
| 是否羞辱儿童 | **无辱骂**；存在道德绑架式羞辱风险（“真正的朋友”） |

### 7.2 与 P0 教育委员历史关切的对齐

P0 纪要教育侧要求：“须写清同伴交往降级，避免挤占正常社交”。P0 终裁接受 MVP 统一 S1、降级延后 P4——**前提是 S1 保持软提醒**。  
P1 数据标签遵循了终裁，但 **refusal 扩写把 S1 写成阻止**，等于在产品层收回了教育妥协，必须会后纠正。

### 7.3 建议的儿童侧文案原则（供 FIX）

```text
S1（含同学问年级）：说明现象 + 赋权选择 + 可继续；不拦截；不道德审判同伴；不默认扰监护人
S2：清楚阻止高风险外发（学校定位/联系方式等）+ 给可执行拒绝句；仍不羞辱
S3：监护人/本地摘要最小化；不对社交对端展示细节
```
