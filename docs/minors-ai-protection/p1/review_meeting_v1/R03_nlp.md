## 2) 一句话结论

八标签均衡与 S0≥25% 已具备可开训的规模底座，但 **94% 样本依赖人工数字盐制造“伪唯一”**，去盐后 train∩test 近重复约 **800 形 / 覆盖 7.4% test 行**，叠加抽检未闭环，会显著虚高 P2 评测可信度。

## 3) 核心量化结论（训练就绪视角）

### 3.1 规模与类别均衡 — 达标

| 指标 | 实测（train） | 判定 |
|---|---|---|
| n | 30000 | 达标（目标 3 万） |
| 8 标签正例 | 2728–2913 | **优秀均衡**（max/min≈**1.068**） |
| S0（`labels=[]`） | 8400（**28.0%**） | 达标（门禁 ≥25%） |
| 等级 | S0 8400 / S1 5219 / S2 11931 / S3 4450 | S2 偏重但可解释（多数标签默认 S2） |
| 每标签 test 正例 | ≥1707 | 远超门禁，足够宏 F1 统计 |

**可学性（均衡维度）**：多标签 sigmoid / BCE 不会被极端长尾拖垮；每类约 2.7k–2.9k 正例对轻量端侧模型足够开训。

### 3.2 多标签共现 — 偏薄但结构正确

| 指标 | train | test |
|---|---|---|
| 0 标签（S0） | 8400（28.0%） | 1687（10.9%） |
| 1 标签 | 20725（69.1%） | 13254（85.7%） |
| ≥2 标签 | **875（2.92%）** | 517（3.34%） |
| 来源 | 全部 `source=combo` | 含 combo + 少量 golden |

Top 共现（train）：

| 共现对 | 次数 |
|---|---|
| offline_meeting + privacy_request | 75 |
| offline_meeting + school_request | 66 |
| privacy_request + threat | 66 |
| age_probe + contact_request | 63 |
| emotional_manipulation + photo_request | 62 |
| offline_meeting + threat | 60 |

**判定**：共现覆盖了 P0 高危组合（年龄+联系、线下+隐私/学校、威胁组合），但对「多标签联合决策」学习信号偏稀（<3%）。不阻塞开训，但 P2 若要报多标签联合指标，需在后续版增厚 combo（建议 ≥8–10%）。

### 3.3 文本同质化与盐值标记 — **P1 级风险**

生成器 `tools/synthesize_batch.py::stylize()` 在给定 `salt` 时**强制**插入下列标记之一：

`我说第{salt}次` / `认真问哦·{salt}` / `别打哈哈#{salt}` / `回我一句就行（{salt}）` / `就问这一下-{salt}` / `拜托回一下/{salt}` / `别敷衍{salt}号问题` / `这次算{salt}`

| 指标 | train | test | adv |
|---|---|---|---|
| 含盐记比例 | **94.11%** | 92.60% | 86.40% |
| 「我说第N次」 | 3562 | 1756 | 52 |
| 「问法」字面 | **0** | — | — |
| raw unique ratio | **1.000** | 1.000 | 1.000 |
| 去盐后 unique ratio | **0.964** | 0.968 | 1.000 |
| 去前后缀+盐后正例核心形 | 9094 | — | — |
| 核心形 count≥20 的正例质量占比 | **26.9%** | — | — |

来源维盐覆盖：`template/combo/normal` = **100%**；`paraphrase`≈85%；`seed_p0`=0。

底层模板库存仅 **8×30=240** 句式 + 槽位填充；盐把字面唯一率抬到 100%，但语义多样性被掩盖。模型可能：

1. 学到「长数字 / 第N次 / 别打哈哈#」为无意义噪声（浪费容量）；或  
2. 把盐模式当捷径特征（部署无盐真实流量时分布偏移）；或  
3. 因去盐近重复跨 split，在评测上**虚高泛化**。

同质化例（同一去盐核、仅盐不同）：

- `TR02645`：出来走走，别只网上聊，就问这一下-5504108  
- `TR08174`：出来走走，别只网上聊，我说第5004288次  
- `TR16972`：出来走走，别只网上聊，别敷衍5502518号问题  

### 3.4 train–test 泄漏 — 形式 PASS，实质 **近泄漏 P1**

| 检查 | 结果 |
|---|---|
| 规范化全文跨 split 交集（validator 同款） | **0**（train∩dev/test/adv 全 0） |
| P0 golden → train | **0**（40 条均在 test，`source=seed_golden`） |
| **去盐后** train∩test 相同形 | **800** |
| 去盐后 train∩dev | **626** |
| 去盐后 dev∩test | **441** |
| test 行存在 train 去盐孪生 | **1144 / 15458 = 7.40%** |
| 近重复标签一致性 | 800/800 标签一致（非标错，是**模板克隆跨 split**） |

近泄漏对例：

| split | id | text 片段 |
|---|---|---|
| train | TR18003 | 拜托回一下/5004061，下课后在校门右侧等我 |
| test | TE03571 | 拜托回一下/5000221，下课后在校门右侧等我 |
| train | TR23222 | 就问这一下-6004076，不按我说的做就别说喜欢我 |
| test | TE07878 | 就问这一下-6005876，不按我说的做就别说喜欢我 |

**判定**：现行 `validate_p1.py` 只做 `normalize(text)` 精确去重，**被盐绕过**。对 P2 而言这是评测可信度的实质泄漏，应升为门禁（去盐 / 去模板核后再查交集）。

### 3.5 长度与表层多样性

| 指标 | train |
|---|---|
| 平均长度 | **29.16** 字 |
| 中位 / P90 | 29 / 36 |
| 长度桶 | 20–39 占 **91.2%**；<10 仅 166 |
| 会话前缀命中（那个/诶/话说…） | 6159（20.5%） |
| 5k 抽样去盐字符 trigram unique ratio | 0.100 |

短单句符合 Data Card「单句/短句」定位，可训词级/字级分类器；但对多轮 grooming、慢诱导几乎无信号（已知限制，P4）。

### 3.6 S0 / 硬负例与误拦控制

| 子集 | n | 占 train |
|---|---|---|
| S0 合计 | 8400 | 28.0% |
| `normal` | 8156 | 27.2% |
| `hard_negative` | **244** | **0.81%** |

- S0 盐记比例 **99.4%**（正常闲聊也被插入「回我一句就行（N）」等诱导口吻）→ **会污染负例分布**，推高「正常句也像追问」的假阳性风险。  
- hard_negative 绝对量过低（244），边界易混负例学习信号不足。  
- 启发式扫描：`normal` 且含微信/自拍/见面等风险词 = **0**（正常句本身干净，但被盐口语化）。

### 3.7 噪声与可学性

| 信号 | 实测 | 影响 |
|---|---|---|
| `review_status=auto` | **29931/30000（99.77%）** | 标签噪声未知上界 |
| 抽检计划 | 目标 ≈288；`v0.3_spot_check_ids.txt` 仅 **84** 且偏 train | 门禁未执行 |
| findings / 签字 | **缺失** | 不可冻结 |
| 规则等级启发 | threat→S3；offline+时间地点→S3 | 可复现，但未人工校准 |
| 源构成 | paraphrase 37.4% / template 31.6% / normal 27.2% / combo 2.9% / HN 0.8% / seed 0.1% | 高度模板驱动 |

**可学性综合**：意图关键词（微信、自拍、校门、住址…）与标签对齐度看起来高，**浅层模型容易拟合模板关键词**并在同源 test 上刷分；换真实/无盐分布后召回与误拦均可能塌方。故「能学」≠「学到可部署特征」。

### 3.8 adv / refusal（算法侧最小可用性）

- adv=500，全单标签，盐记仍 86%；变换以空格插入/谐音替换为主 → **最小对抗集**，不足以压力测试鲁棒性。  
- refusal=500，文本全唯一；算法训练不直接依赖，但 S1/S2 产品联动可用。

### P1（显著损害 P2 训练/评测可信度）

1. **FIX-R03-01｜消除盐驱动的跨 split 近泄漏**  
   - 路径：`tools/synthesize_batch.py`（`stylize` 盐逻辑）、`tools/validate_p1.py`（泄漏检查）、升版 `datasets/v0.4/` 或冻结前清洗  
   - 动作：  
     a) 训练/评测文本去掉无语义盐（`我说第N次`、`#digits`、`（6–7位数字）` 等）；或盐仅写入 metadata 不进 `text`；  
     b) validator 增加 **去盐 normalize** 与可选 **模板核** 交集检查，要求 train∩{dev,test,adv}=0；  
     c) split 前按去盐键去重再划分。  
   - 阻塞：正式 P2 指标验收 / `p1-v1.0` 冻结  

2. **FIX-R03-02｜完成分层抽检 ≥95%**  
   - 路径：`reports/spot_check_plan.md`、`reports/v0.3_spot_check_ids.txt`（现仅 84≪288）、新建 `reports/v0.3_spot_check_findings.md`  
   - 动作：按计划覆盖 train 每标签 / hard_neg / test / combo / adv；无 findings 不得宣称可学标签可信。  
   - 阻塞：冻结与正式开训验收  

3. **FIX-R03-03｜清洗 S0 负例上的追问式盐口吻**  
   - 路径：同上生成器；重点 `source=normal`  
   - 动作：S0 禁止使用「回我一句就行 / 别敷衍N号问题 / 我说第N次」等施压口吻盐；保留中性多样性手段（同义、语序、标点）。  
   - 阻塞：误拦控制可信度（与 S0 门禁同级）  

### P2（应改，不单独否决 rc 探索训）

4. **FIX-R03-04｜增厚多标签 combo 与 hard_negative**  
   - 目标建议：combo ≥8%；hard_negative ≥3–5% of train（或 ≥1500）  
   - 路径：`synthesize_batch.py`、`datasets/v0.4/`  

5. **FIX-R03-05｜扩展模板/释义多样性**  
   - 现状 240 模板撑 3 万样本；建议每标签模板 ≥80，或引入复核后的 LLM paraphrase（`review_status` 升级）  

6. **FIX-R03-06｜adv 去盐并增加无盐对抗**  
   - 避免 adv 与 train 共享盐族特征；补充谐音/拆字/emoji/慢诱导

## 6) 七问简答

1. **是否坚持合成红线（无真实未成年私密）？**  
   **是（就本委员可见证据）**。源为 P0 seed/golden + 模板/改写；未见真实私密聊天导入。

2. **train/dev/test/adv 隔离与 golden 不进 train 是否成立？**  
   **形式成立、实质部分不成立**：精确规范化泄漏=0，golden∩train=0；但去盐后 train–test 近重复显著（7.4% test 行），隔离被盐击穿。

3. **8 标签可学性与类别均衡是否足以开 P2？**  
   **均衡足以开探索性 P2**；可学性受模板同质化与盐捷径制约，正式验收前需 FIX-R03-01/02。

4. **S0/硬负例是否足以控制误拦？**  
   **数量门禁达标（28%），质量存疑**：hard_negative 仅 244；S0 普遍带追问式盐，不利于误拦建模。

5. **adv/拒绝话术是否达到最小对抗与产品可用？**  
   **达到最小可用，未达鲁棒**。adv=500 偏薄且仍含盐；refusal=500 文本唯一，产品侧可用。

6. **Data Card / 溯源 / 版本纪律是否可审计？**  
   **基本可审计**（Card、stats hash、分版目录、schema 字段齐全）；但 `review_status=auto` 主导且抽检未闭环，质量溯源不完整。

7. **可否冻结并开 P2？**  
   **有条件：可开 P2 探索训 / 不可冻结 v1.0**。须先完成去盐近泄漏治理与抽检 ≥95%，方可冻结并作正式指标基线。
