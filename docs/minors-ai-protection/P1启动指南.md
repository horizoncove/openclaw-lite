# P1 启动指南：合成数据与评测基准

P1 目标：在**合成数据红线**下，做出可训练、可回归的数据资产。  
依赖：**P0 已冻结为 `p0-v1.0`（人类已签字）**。  
本阶段**不训练模型**（训练在 P2）；本阶段只造数、质检、冻结评测集。

---

## 0. 开工前清单（Day 0）

```text
□ 确认 p0-v1.0 人类签字（见 p0/HUMAN_SIGN_OFF.md）
□ 指定 P1 Owner（当前：Agent-001）
□ 宣读红线：仅合成；禁止真实未成年私密聊天
□ 标签冻结：MVP 8 key 不得擅自增减
□ 建工作区 docs/minors-ai-protection/p1/
□ 约定交付：数据集（当前推荐 v0.3，train 3 万）+ Data Card + 校验 PASS
```

### Kickoff 只拍 5 件事

1. P1 Owner 与周更对象  
2. 目标规模：train ≥1500（冲 3000）/ eval ≥500 / 每标签 test ≥40  
3. 流水线：模板为主 + 可选 LLM 辅助 + 人工抽检  
4. 划分策略：train / dev / test 严格隔离（含文本去重）  
5. 验收：抽检通过率 ≥95%，validator PASS

## 4. 样本字段（强制）

```text
id                 唯一 ID，如 T000123 / E000045
text               合成中文单句或短句
labels             字符串数组；S0 用 []
expected_level     S0|S1|S2|S3（S4 不进训练集自动标）
reason_codes       与 labels / 升级规则对应
split              train|dev|test|adv
source             seed_p0|template|paraphrase|combo|normal|refusal_seed
review_status      auto|spot_checked|needs_review|rejected
annotator          生产者 ID
notes              可选说明
ts                 ISO 日期
```

禁止字段：真实用户 ID、设备号、可还原原文的旁路存储。

---

## 5. 规模目标与门禁

| 指标 | MVP 门槛 | 冲刺目标 |
|---|---|---|
| train | ≥1500 | **30000（已达 v0.3）** |
| eval（dev+test+adv） | ≥500 | 800+（v0.3≈28169） |
| 每 MVP 标签 test 正例 | ≥40 | ≥50（v0.3≥1707） |
| normal / 硬负例占比 | train 中 ≥25% | ≥28% |
| 拒绝话术 | ≥200 | 300+（v0.3=500） |
| 抽检正确率 | ≥95% | ≥97% |
| train↔test 文本重复 | 0（规范化后） | 0 |
