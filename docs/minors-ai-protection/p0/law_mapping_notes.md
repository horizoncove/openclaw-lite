# 条款映射审校说明（强化版）

`law_mapping.csv` 当前为 **义务对齐草稿**，不是正式法律意见书。

## 使用方式

1. 法学同事按 `map_id` 逐条核对 `clause_ref`  
2. 可改为更精确的条、款、项  
3. 核对后将 `law_mapping.csv` 状态视为 `reviewed`  
4. 未复核前对外材料须注明“研究草案”

## 映射原则

- 一条标签/场景可对应多条义务（多行）  
- `system_control` 必须能落到 S0–S4 动作或审计能力  
- 不声称“本系统已满足全部法定义务”  
- 不做刑事取证承诺（S4 仅预留）
