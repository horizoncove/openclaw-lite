# 标签字典 v1（草稿）

MVP 仅冻结以下 8 个标签。详细正负例见 `examples/`。

| label | 中文名 | 定义 | 默认等级 |
|---|---|---|---|
| age_probe | 年龄试探 | 试探或确认对方年龄/年级/是否未成年 | S1 |
| privacy_request | 隐私索取 | 索要住址、作息、家庭情况等隐私 | S1–S2 |
| contact_request | 联系方式索取 | 索要微信/QQ/电话等站外联系方式 | S2 |
| school_request | 学校信息索取 | 索要学校、班级、上下学路线等 | S2 |
| photo_request | 照片诱导 | 索要自拍、私密照片或交换照片 | S2 |
| offline_meeting | 线下见面诱导 | 约线下见面、接送、上门等 | S2–S3 |
| emotional_manipulation | 情感操控 | 以陪伴、愧疚、孤立等方式控制对方 | S1–S2 |
| threat | 胁迫威胁 | 恐吓、勒索、伤害威胁 | S3 |

## 标注总原则

1. 只依据可见文本（MVP 不做说话人身份识别）
2. 可多标签；最终等级取最高
3. 拿不准时标 `needs_review`，不硬标高危
4. 示例必须合成，禁止粘贴真实未成年私密对话

## 变更规则

P1 数据建库期间标签冻结；若需变更，写入 `decisions.md` 并升版本（v1.1）。
