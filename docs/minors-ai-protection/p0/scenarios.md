## SCN-STR-01 陌生人搭讪开场

- 关联标签: age_probe, emotional_manipulation（可后继）
- 典型路径: 搭讪示好 → 快速亲密称呼 → 转入年龄/学校试探
- 受害风险: 建立不对称信任，降低防备
- 常见话术类型: 你好呀妹妹/弟弟；交个朋友；看你很有趣
- 处置倾向: 单独开场多为 S0/S1；一旦出现试探标签按对应等级
- 备注: MVP 不单独作为高危标签，作为场景上下文

## SCN-AGE-01 年龄试探

- 关联标签: age_probe
- 典型路径: 搭讪 → 问年级/是否成年 → 调整诱导策略
- 受害风险: 定向识别未成年人
- 常见话术类型: 直接问年龄 / 问年级 / 猜年龄 / 问是否成年
- 处置倾向: 首次 S1；反复或叠加索联升 S2
- 备注: 同学互问年级 MVP 暂统一可标，降级留给 P4

## SCN-PRI-01 隐私索取

- 关联标签: privacy_request
- 典型路径: 关心姿态 → 问家庭住址/作息/独居情况
- 受害风险: 暴露生活规律与家庭环境
- 常见话术类型: 家住哪 / 父母是否在家 / 几点放学 / 是否一个人
- 处置倾向: S2（涉及住址/独居/作息）；轻度家庭闲聊可 S1
- 备注: 与 contact_request 区分：本标签不主攻微信号/电话

## SCN-CON-01 联系方式索取

- 关联标签: contact_request
- 典型路径: 示好 → 称站内不方便 → 要微信/电话
- 受害风险: 脱离平台防护进入私域
- 常见话术类型: 加微信 / QQ / 手机号 / 其他 App 账号
- 处置倾向: S2 阻止
- 备注: MVP 最高频可演示场景之一

## SCN-SCH-01 学校信息索取

- 关联标签: school_request
- 典型路径: 套近乎 → 问学校名/班级/校门位置/放学路线
- 受害风险: 定位到线下可接触空间
- 常见话术类型: 哪个学校 / 几班 / 哪个校区 / 怎么放学
- 处置倾向: S2；与 offline_meeting 共现可升 S3
- 备注: “作业难不难”等无定位意图不标本标签

## SCN-PHO-01 照片诱导

- 关联标签: photo_request
- 典型路径: 赞美外貌 → 要自拍/近照 → 可能进一步要更多照片
- 受害风险: 形象被滥用、隐私泄露、诱导升级
- 常见话术类型: 发张自拍 / 看看你长什么样 / 互换照片
- 处置倾向: S2
- 备注: 不做色情内容检测；只识别“索要个人照片”行为

## SCN-OFF-01 线下见面诱导

- 关联标签: offline_meeting
- 典型路径: 熟悉感 → 陪伴承诺 → 约见面/接送
- 受害风险: 人身安全风险
- 常见话术类型: 见一面 / 接你放学 / 来找你 / 指定地点时间
- 处置倾向: 明确邀约 S2；含具体时间地点 S3
- 备注: 与 threat 共现 → S3

## SCN-EMO-01 情感操控

- 关联标签: emotional_manipulation
- 典型路径: 过度陪伴 → 制造愧疚/依赖 → 提出越界要求
- 受害风险: 削弱拒绝能力，为后续索取铺路
- 常见话术类型: 你是不是不在乎我 / 那我不管你了 / 只有我懂你
- 处置倾向: 单独 S1；驱动索联/见面/照片时升 S2
- 备注: 与正常安慰区分见 examples

## SCN-THR-01 胁迫威胁

- 关联标签: threat
- 典型路径: 要求被拒 → 恐吓曝光/伤害/报复
- 受害风险: 强制服从、心理恐惧
- 常见话术类型: 不听话就怎样 / 威胁告诉别人 / 扬言伤害
- 处置倾向: S3 告警
- 备注: MVP 高召回优先

## SCN-BUL-01 网络欺凌

- 关联标签: threat, emotional_manipulation
- 典型路径: 羞辱孤立 → 群体排挤 → 威胁传播隐私
- 受害风险: 心理健康与隐私二次伤害
- 处置倾向: S2–S3
- 备注: MVP 用 threat/emotional_manipulation 覆盖，不单开标签
