# 用户侧提示文案库（P0 预置，供 P3 调用）

原则：冷静、可执行、不羞辱、不泄露检测细节给潜在加害者。

## S1 提醒（可继续）

| code | 文案 |
|---|---|
| COPY_S1_AGE | 对方在询问你的年龄或年级。如感到不适，可以不回答，或告诉信任的大人。 |
| COPY_S1_EMO | 这句话可能在对你施加情绪压力。你有权拒绝，不必证明什么。 |
| COPY_S1_GENERIC | 检测到可能不合适的话题。请小心分享个人信息。 |

## S2 阻止发送

| code | 文案 |
|---|---|
| COPY_S2_CONTACT | 为了你的安全，系统已阻止发送可能涉及交换联系方式的内容。 |
| COPY_S2_SCHOOL | 已阻止可能泄露学校或放学路线等信息的内容。 |
| COPY_S2_PRIVACY | 已阻止可能泄露住址或家庭隐私的内容。 |
| COPY_S2_PHOTO | 已阻止可能涉及发送个人照片的内容。请勿向陌生人发送自拍。 |
| COPY_S2_OFFLINE | 已阻止可能涉及线下见面邀约的内容。如对方继续邀请，请告知家长或老师。 |
| COPY_S2_GENERIC | 该消息可能存在安全风险，已被阻止发送。 |

## S3 本地告警（给监护人/本地事件，不对陌生人展示细节）

| code | 文案（监护人侧摘要示例） |
|---|---|
| COPY_S3_ALERT | 设备检测到一条严重风险互动（如威胁或具体见面安排）。详情仅保存在本地脱敏事件中。 |
| COPY_S3_THREAT | 检测到疑似威胁或胁迫内容，建议尽快关心孩子并必要时求助。 |
| COPY_S3_OFFLINE | 检测到包含具体时间或地点的见面诱导，建议立即关注。 |
