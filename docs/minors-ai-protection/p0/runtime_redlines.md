# 运行时红线（评审 FIX-05 / FIX-06）

状态：`p0-v1.0-rc1` 强制条款

## 1. 数据红线

```text
✓ 仅使用合成样本做训练/评测种子
✗ 真实未成年私密聊天原文
✗ 证据包/审计日志包含原文或可逆还原内容
✗ 以“授权脱敏”名义绕开合成红线导入私密原文
✗ 与成人业务线共用语料、模型权重、标注账号
```

## 2. 审计与证据包最小完备字段

| 字段 | 必填 | 说明 |
|---|---|---|
| event_id | 是 | 唯一事件 ID |
| session_id | 是 | 会话 ID |
| ts | 是 | 时间戳 |
| labels | 是 | 命中标签 |
| scores | 是 | 分数 |
| level | 是 | S0–S4 |
| action | 是 | allow/warn/block/alert/escalate |
| reason_codes | 是 | 原因码 |
| rule_ids | 是 | 触发的 Uxx / 默认映射 |
| content_hash | 是 | 原文哈希 |
| hash_alg | 是 | 固定 `sha256` |
| model_ver | 是 | 模型版本 |
| rule_ver | 是 | 规则版本 |
| schema_ver | 是 | 当前 `1.0.0-rc1` |
| mapping_ver | 是 | 条款映射版本（draft 可） |

**禁止字段：** raw_text、image_bytes、可还原切片、完整通讯录等。

## 3. S3 监护人摘要最小化

仅可包含：等级、标签中文名、时间、建议动作；  
不可包含：原文、对方账号明文、精确定位原文。

## 4. 会话记忆

- 窗口：10 分钟（U01）  
- MVP：内存态，杀进程不持久化  
- 会话结束可清除
