## 4. 立刻可用的内容模板

### 4.1 MVP 8 标签（先冻结，勿扩张）

| label | 中文名 | 一句话定义 | 默认倾向等级 |
|---|---|---|---|
| `age_probe` | 年龄试探 | 试探、确认或暗示对方年龄段 | S1 |
| `privacy_request` | 隐私索取 | 索要个人隐私信息（非联系方式为主） | S1–S2 |
| `contact_request` | 联系方式索取 | 索要微信/QQ/电话等站外联系方式 | S2 |
| `school_request` | 学校信息索取 | 索要学校、年级、班级、上下学路线等 | S2 |
| `photo_request` | 照片诱导 | 索要自拍、私密照片或交换照片 | S2 |
| `offline_meeting` | 线下见面诱导 | 约线下见面、接送、上门等 | S2–S3 |
| `emotional_manipulation` | 情感操控 | 以陪伴/威胁分手/愧疚驱动控制对方 | S1–S2 |
| `threat` | 胁迫威胁 | 恐吓、勒索、伤害威胁 | S3 |

P4 再加：`gift_exchange`、`grooming_sequence`、`help_request` 等。

### 4.2 场景库写法（每个场景一节）

复制到 `scenarios.md`：

```markdown
## 场景：年龄试探
- 场景ID: SCN-AGE-01
- 关联标签: age_probe
- 典型路径: 搭讪 → 问年级/是否成年 → 调整话术
- 受害风险: 便于后续定向诱导
- 常见话术类型: 直接问年龄 / 问年级 / 看证件 / 猜年龄
- 处置倾向: 首次 S1 提醒；反复追问可升 S2
- 备注: 同学间正常问年级需靠上下文降级（P4 再细化）
```

### 4.3 标签字典写法（每个标签一节）

复制到 `labels.md` / `examples/age_probe.md`：

```markdown
## label: age_probe
### 定义
询问、试探或诱导对方暴露年龄、年级、是否未成年。

### 包含
- 你几岁了 / 上初中吗 / 是不是还没成年
- 猜你年龄 / 看起来不像大人

### 不包含（负例边界）
- 家长问孩子作业相关年龄题（非社交诱导语境）
- 明确的官方年龄验证流程文案

### 正例（合成，≥20）
1. "你今年多大了呀，感觉好年轻"
2. "你是初中还是高中？"
...

### 易混负例（≥10）
1. "这个游戏年龄评级是 12+"
...

### 默认等级
S1；若与 contact_request/offline_meeting 共现，取更高者
```

### 4.4 S0–S4 建议表（直接进 `severity.md`）

| 等级 | 名称 | 默认动作 | 触发原则（MVP） | 是否上传原文 |
|---|---|---|---|---|
| S0 | 正常 | 允许 | 无风险标签或分数低于阈值 | 否 |
| S1 | 可疑 | 提醒，可继续 | 单一低危标签（如首次 age_probe） | 否 |
| S2 | 高风险 | 阻止发送 | contact/school/photo/offline 等高危命中 | 否 |
| S3 | 严重风险 | 本地告警事件 | threat，或 offline 反复升级 | 否 |
| S4 | 强制处置 | 仅预留接口 | MVP 不自动触发 | 否 |

升级示例（先写进规范，P3 再编码）：

```text
同会话 10 分钟内同类 S1 命中 ≥3 次 → 升 S2
age_probe + contact_request 同句/相邻 → 至少 S2
offline_meeting 明确邀约 → S2，附加地点/时间细节 → S3
```

## 6. “可被规则引擎编码”检查清单

算法在 D11 必须回答 YES：

```text
□ 每个标签有稳定英文 key
□ 每个等级有唯一 action 枚举：allow/warn/block/alert/escalate
□ 有明确共现/频次升级规则（哪怕 5 条）
□ 输出原因码枚举（如 R_AGE_PROBE）
□ 不依赖“模型自己体会”的模糊词作为唯一依据
□ 日志字段已列出：label, score, level, action, content_hash, model_ver, rule_ver
```

做不到以上 = P0 未完成，不要进 P1。
