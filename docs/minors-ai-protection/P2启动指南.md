## 2. 模型目标（MVP）

| 项 | 目标 |
|---|---|
| 类别 | 8 标签多标签 + normal |
| 体积 | ≤ 30MB |
| P95 时延 | ≤ 80ms（中端机，目标；首版可先报 CPU） |
| 宏平均 F1 | ≥ 0.80 |
| contact/offline/threat 召回 | ≥ 0.90 |
| 正常样本 S2+ 误拦 | ≤ 3%（与 P1 test/S0 对齐） |
