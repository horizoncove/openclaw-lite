# 06 · 数据治理：采集、脱敏、留存、导出

版本：`minorguard-devdocs-v0.1`

## 1. 数据分类

| 级别 | 示例 | 存储策略 |
|---|---|---|
| L0 禁止入库 | 云 API Key、真实证件号全文、未授权原始聊天库 | 永不进入 Git / DB / 导出 |
| L1 高敏 | 完整对话原文、未掩码联系方式 | 默认不落库；分析过程内存处理 |
| L2 脱敏事件 | snippet、标签、分数、版本、时间 | 可落库，受角色访问控制 |
| L3 聚合统计 | 等级分布、分类计数 | 可进运营/监管视图 |
| L4 公开文档 | 本目录开发文档、合成样例说明 | 可公开 |

## 2. 采集范围

### 可采集（授权后）

- 用户主动提交或平台 SDK 传入的对话文本（有长度上限）
- 系统生成的风险结构化结果
- 管理操作审计元数据（时间、动作、路径、角色）

### 不可采集

- 设备通讯录、精确持久定位、短信、相册（除非未来独立产品且单独授权——P3 不做）
- 其他 App 数据
- 生物特征

## 3. 脱敏规则（最小实现）

写入事件前必须经过 `maskSensitiveText` 类处理：

| 类型 | 规则（示例） |
|---|---|
| 手机号 | 保留前3后4，中间 `****` |
| 身份证 | 保留前3后2，其余 `*` |
| 邮箱 | 本地名首尾保留 |
| 具体住址门牌 | 替换为 `[地址已脱敏]` |
| 姓名（若可识别模式） | `[姓名已脱敏]` |

`summary` / `hits` / `reason` 不得回显原始高敏串。

## 4. 留存

| 数据 | 默认留存 | 说明 |
|---|---|---|
| 事件 L2 | 可配置，建议 ≤ 180 天 | P3 先支持配置项 `EVENT_RETENTION_DAYS` |
| 审计日志 | ≥ 事件留存 | 安全追责 |
| 红队报告 | 工程产物 | 不含生产 PII |
| 内存中的原文 | 请求结束释放 | 不写交换文件 |

到期删除任务可在 P3 Should 实现；Must 至少文档化配置项与手动清理接口。

## 5. 导出

- 默认导出 = 再脱敏后的 L2/L3
- 监管视图优先聚合；明细导出需 admin 且审计
- 导出文件命名含时间戳与版本，不含用户真名

## 6. 训练数据隔离

- 产品运行数据 **不得** 直接回流训练
- 研究轨仅使用合成数据（`p1-v1.0` 红线）
- 若未来需难例挖掘：必须二次脱敏 + 人工审核 + 单独授权记录

## 7. 跨境与第三方

- 使用境外/第三方大模型时，应在部署说明中披露
- 试点若要求数据不出境，则 `CLOUD_LLM_ENABLED=false`，仅本地规则 + 端侧模型
