# Sharon Trading System v1.0

个人量化交易助手桌面 MVP，使用 Python 3.11+、PyQt6 和 SQLite。数据只保存在本机，不连接券商，也不会自动下单。

## Windows 安装版

自动构建产物 `SharonTradingSystem-Setup.exe` 是免管理员权限的 x64 安装程序，包含 Python 和 PyQt6 运行环境，目标电脑不需要安装 Python。运行安装程序后可选择创建桌面快捷方式，并可从 Windows“已安装的应用”中卸载。

应用数据保存在当前用户的本地应用数据目录，升级或卸载程序不会误删交易数据库：

```text
%LOCALAPPDATA%\Sharon\Sharon Trading System\data\sharon_trading.db
```

仓库的 `Build Windows Installer` 工作流同时生成安装程序和单文件免安装版。

## 已实现

- 外部 AI 候选股票记录，当前候选池限制为 2–3 只
- 驾驶舱首页：账户 KPI、仓位/现金环形仪表、候选池、板块分布、风险灯号与纪律评分
- 当前持仓股票仪表卡：数量、成本、最新价、市值、仓位、浮动盈亏和 -7% 止损价
- 支持持久化深色科技主题切换，驾驶舱采用深蓝/青色数据终端视觉
- 遵循 A 股红涨绿跌习惯：盈利红色、亏损绿色
- 保存股票代码、名称、板块、来源 AI、外部评分和入选理由
- 软件不执行 SOP 评分、不推荐股票，和外部选股 AI 职责完全分离
- 交易前红黄绿测算，非候选股票、硬红线和禁买时段自动拦截
- 3 步建仓阶段、浮盈 10% 加仓检查和最多加仓一次
- L1/L2/L3 监督记录、违规处罚升级及月度 A/B/C/D 评分
- 15:30 每日复盘、主动空仓决策、十项任务状态面板
- SQLite 持久化的 5 秒成交同步队列，重启后不会丢失
- 账户与交易流水 CSV 导出，用于和既有本地文件核对
- 账户起始资金、当前总额和累计盈亏持久化
- 持仓市值、仓位比例、现金和板块仓位实时计算
- 支持 `买入 002371 350.00 3600`、`卖出 002371 355.00 1000`
- 买入采用移动加权平均成本，禁止超持仓卖出
- 单票 25%、板块 30%、总仓位 60%、现金 40% 四类红线
- 账户总览、候选池、持仓、交易流水、风险、计划、监督、复盘和任务界面

金额统一以人民币元写入数据库，界面以“万元”显示。PDF 基准为起始资金 5,000,000 元、当前总额 5,037,175.21 元、累计盈亏 37,175.21 元。

> SOP 分析和选股由外部 AI 完成，本软件只接收最终 2–3 只候选股票。纪律索引仍未给出“五种强制空仓情况”的具体定义，因此这五项继续作为明确标注的可配置条件。

## 安装与启动

在仓库根目录执行：

```bash
python3 -m pip install -r sharon_trading_system_v1_0/requirements.txt
python3 -m sharon_trading_system_v1_0.main
```

无桌面的精简 Ubuntu 镜像若提示缺少 `libEGL.so.1`，先执行：

```bash
sudo apt-get update
sudo apt-get install -y libegl1 libgl1
```

数据库首次启动时自动创建在操作系统的当前用户应用数据目录。

## 使用

1. 在“候选股票”登记外部 AI 最终选出的 2–3 只股票。
2. 在“当前总额”输入框更新账户净值。
3. 输入交易指令，可额外填写板块。
4. 点击“加入同步队列”；系统在下一个 5 秒周期写入交易。
5. 在“实时持仓”“交易流水”和“风险中心”查看结果。

同步数据代表券商已经成交的事实，因此即使成交后触发红线，交易仍会入库，同时生成风险告警。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

若服务器没有图形桌面，可使用 Qt 的离屏模式进行界面冒烟测试：

```bash
QT_QPA_PLATFORM=offscreen python3 -m unittest tests.test_sharon_app -v
```

## 当前边界

- 当前版本不连接真实券商或行情源；成交价即该股票的最新估值价格。
- 暂未计算手续费、税费和已实现/未实现盈亏拆分。
- SQLite 适合单机个人使用，不适合作为多人并发交易后台。
