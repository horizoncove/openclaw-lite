## 快速开始

```bash
cd xian-drama-saas && npm install && npm run dev
```

| 入口 | 路径 |
|------|------|
| 会员中枢 | `/app/login` → `/app/workspace` |
| **监管监督视角** | 陈希/韩磊登录 → `/app/supervision` |
| 演示壳 | `/overseas` · `/alliance` · `/center` |

生产：`npm run build && npm start`
