# 西安微短剧产业服务中心 · 运营 SaaS

联盟运行 SaaS + 五大中心运营 SaaS 一体化演示系统。

## 模块

### 总控
- 运营总览
- 工单中枢（跨中心 SLA）
- KPI 看板

### 联盟运行 SaaS
- 会员管理（层级/标签/状态）
- 活动运营（对接会/路演/培训）
- 供需撮合

### 五大中心运营 SaaS
- 审批中心：备案预检流水线
- 出海中心：选品→译制→谈判→上线漏斗
- 发行投流：体检/冷启动/复盘
- 版权中心：确权/授权/维权台账
- AI 研发：四条产线接入与效果

## 启动

```bash
cd xian-drama-saas
npm install
npm run dev
```

浏览器打开本地地址后，选择角色登录即可。数据保存在 `localStorage`，可点「重置演示数据」。

## 构建

```bash
npm run build
npm run preview
```
