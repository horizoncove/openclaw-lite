## 1. 为什么升到 V1.3

V1.2 拍板了正确主轴（会员中枢 + 无转售 + API/算力），但外部演示与内部实现暴露三类缺口：

1. **分层不清**：出海营销站、撮合大盘、会员中枢三套叙事互相抢「唯一 SaaS」话术  
2. **钱的语义混**：API/算力用 Tokens，撮合托管像法币，未写清「禁止互转」  
3. **履约断层**：需求应征确认后缺少标准 **撮合订单**；出海缺少 **服务工单** 回写  

V1.3 = 把已验证的纠偏 **写回正式方案**，作为实现与对外演示的唯一真源。

## 2. 产品三角（强制）

```
                    ┌─────────────────────────┐
                    │  会员协作中枢（主产品）   │
                    │  项目·需求·进度·钱包·网关 │
                    │  算力·通知·撮合订单       │
                    └───────────┬─────────────┘
                                │
              ┌─────────────────┼─────────────────┐
              ▼                                   ▼
   ┌──────────────────┐              ┌──────────────────────┐
   │ 出海专业服务线    │              │ 供需履约网络          │
   │ 营销进件+服务工单 │              │ 需求成交→撮合订单     │
   │ （非独立 SaaS）   │              │ （非 Token 市场）     │
   └──────────────────┘              └──────────────────────┘
```

| 表面 | 职责 | 禁止 |
|------|------|------|
| **会员中枢** | 日常经营 + Tokens 计量 + 作业调度 | 宣称已等保/多区域上线 |
| **出海服务** | SOP 卖点、咨询进件、工单进度 | 替代中枢；Token 盘 |
| **撮合履约** | 应征成交后的订单/托管/放款叙事 | 额度挂单、机构间余额转让 |

外部演示索引只保留：中枢主演示 + 出海服务介绍；旧「出海唯一平台」展台标 Deprecated。

## 4. 分期（修订）

### Phase 1（MVP，工程放行以 ACCEPTANCE 为准）

账号机构、项目任务、全联盟需求（含我应征的）、**撮合订单最小闭环**、工作台逾期、Tokens 官方购额、Chat 网关计量、算力作业+退款、通知已读、无转售。

### Phase 1.1

出海服务工单双向同步、订单托管状态细化、usage_records、Key 哈希、鉴权加固、沙箱对接外部演示壳。

### Phase 2

多模型路由、图像/视频、多池调度、子 Key、热度测试真数据（需平台授权）、邮件企微。

### Phase 3

多租户、发票、等保测评与多区域（仅建设计划，不进演示验收）。
