# 西安微短剧产业服务中心

官网展示站点：产业联盟 + 五大专业服务中心（出海 / 审批 / 发行投流 / 版权 / AI 研发）。

## 本地运行

```bash
cd xian-drama-center
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物在 `dist/`。

## 页面结构

1. **首屏** — 品牌与核心定位
2. **产业联盟** — 开放共建与资源互通
3. **五大服务中心** — 可切换详情面板
4. **服务流程** — 入驻到交付四步
5. **入驻对接** — 意向表单与联系方式
