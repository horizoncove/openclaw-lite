# Sharon 融合选股 · 新因子策略与评分标准（v1）

> 状态：现行默认策略（Sharon 桌面端 `mode=fused`）  
> 依据：`knowledge/research/fused_factor_scoring_review.md`  
> 实现：`sharon_trading_system_v1_0/limit_up_strategy.py`

---

## 一、策略定位

收盘后从**当日涨停池**中筛选次日观察/计划标的。只出建议，不自动下单。

最终得分：

```text
最终分 = 七星主分 + 封板质量附加(≤10) − 过热风险罚分
入选条件：通过全部硬过滤，且 七星主分 ≥ 65
排序：按最终分从高到低，默认取 Top 1–3
```

已废弃：旧版「七星50% + 接力25% + V31反向25%」平行加权。

## 二、流程（四步）

### 1) 市场门

| 条件 | 动作 |
|---|---|
| 全市场涨停家数 **< 30** | 弱市空仓，当日不选股 |
| 涨停家数 **≥ 30** | 进入个股硬过滤 |

### 2) 硬过滤（必须全部满足，否则淘汰）

| 因子 | 标准 |
|---|---|
| 连板高度 | **2–4 板**（含）；5 板及以上剔除 |
| 流通市值 | **≤ 100 亿**；**> 300 亿**硬剔；缺市值数据剔除 |
| 换手率 | **≥ 5%** |
| 小市值风险 | 市值 **≤ 30 亿** 且换手 **> 30%** → 剔除 |
| 首次封板 | **早于 14:00** |
| 板块共振 | 所属板块当日涨停 **≥ 3 只** |
| ST | 排除 |

### 3) 七星主分（满分 100，门槛 65）

| 星 | 维度 | 满分 | 计分要点 |
|---|---|---:|---|
| 天枢 | 资金/封单 | 15 | 封单/成交额：≥0.8→15；≥0.35→12；≥0.15→8；否则4 |
| 天璇 | 板块轮动 | 15 | 板块涨停家数：≥6→15；≥4→12；≥3→9；否则3；板块排名前2再+1（封顶15） |
| 天玑 | 情绪周期 | 10 | 全市场涨停：≥80→8；≥50→9；≥30→7；否则3；未炸板+1；炸板≥2则−3 |
| 天权 | 多维强度 | 15 | 换手带 + 封单档 + 炸板档（**强度分**，不用「是否过硬过滤」二项凑分） |
| 玉衡 | 龙头确认 | 20 | 2板16 / 3板14 / 4板10；板块内成交额领先再加分；热门板块第1再+1 |
| 开阳 | 买卖信号 | 15 | 封板越早越高：≤10:00→15；≤11:00→12；≤13:00→9；否则6（已过14:00过滤） |
| 摇光 | 稳定性 | 10 | 未炸+2/3板→8；未炸→6；炸1→4；否则2；市值30–100亿再+2 |

**天权细项（相加后封顶 15）**

| 子项 | 规则 |
|---|---|
| 基础 | 3 |
| 换手 | 8%–18% → +5；5%–8% 或 18%–25% → +3；>25% → +0；其他 → +1 |
| 封单比 | ≥0.8 → +4；≥0.35 → +2.5；≥0.15 → +1 |
| 炸板 | 0次 → +3；1次 → +1 |

**玉衡成交额领先加分**

| 板块内成交额 / 板块最高成交额 | 加分 |
|---|---:|
| ≥ 0.9 | +4 |
| ≥ 0.6 | +2 |

### 4) 附加与罚分（用于排序，不放宽 65 门槛）

**封板质量附加（合计上限 10）**

| 条件 | 加分 |
|---|---:|
| 未炸板 | +4 |
| 首次封板 ≤ 10:00 | +3 |
| 首次封板 ≤ 11:00（且未拿到上一档） | +2 |
| 封单比 ≥ 0.8 | +3 |
| 封单比 ≥ 0.35 | +1.5 |
| 恰好 2 连板 | +2 |

**过热风险罚分**

| 条件 | 扣分 |
|---|---:|
| 换手 > 25% | −4 |
| 炸板 ≥ 2 次 | −5 |
| 4 连板 | −3 |

```text
最终分 = min(100, max(1, 七星主分 + 质量附加 − 罚分))
```

## 三、计划层风控（不改 L1 硬红线）

| 项 | 标准 |
|---|---|
| 硬止损 | −7% |
| 单票仓位 | ≤ 25% |
| 总仓位 | ≤ 60% |
| 战术止盈（参考） | +6% 卖半；+18% 清仓 |
| 节奏（参考） | 周一至周四建仓、每日最多 1 只、周五清仓、最多持有 5 个交易日 |
| 开盘介入带（参考） | 现价相对昨收 ∈ [−3%, +5%] |

落单预检仍以 Sharon L1 更严者为准。

## 四、明确不做的事

1. **不再**把 V31「高波动/突然放量/正乖离」作正向加权。  
2. **不再**用三套完整分数 50/25/25 平行融合（共线 + 目标冲突）。  
3. 手册历史胜率（83.3%、100% 等）**不作为**本标准的参数依据，仅标注「未独立验证」。  
4. 聚宽工程 PY **停止维护**；本标准以 Sharon 桌面端实现为准。

## 五、一句话口径

**先过弱市门与 SOP 硬过滤，再用清洗后的七星主分卡 65 分；封板质量只加分排序，过热只罚分降权。**
