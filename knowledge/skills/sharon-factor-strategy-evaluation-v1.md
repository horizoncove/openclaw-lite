| 旧做法 | 新做法 | 原因 |

## 1. 评估目标

对「当日涨停股」做标准化评估，输出：

1. **市场环境结论**：可评估 / 弱市空仓  
2. **个股硬过滤结论**：通过 / 否决（附原因）  
3. **七星主分**（0–100）与分项明细  
4. **最终分**（主分 + 附加 − 罚分）与池内排序  
5. **评级**：S / A / B / C / 否决  
6. **计划提示**：止损、仓位、节奏（不突破 L1 红线）

## 2. 因子策略总览

```text
                    ┌─────────────┐
                    │  市场门评估  │  涨停家数 ≥ 30？
                    └──────┬──────┘
                           │是
                    ┌──────▼──────┐
                    │ 硬过滤评估   │  一票否决项全过？
                    └──────┬──────┘
                           │是
                    ┌──────▼──────┐
                    │ 七星主分评估 │  ≥ 65？
                    └──────┬──────┘
                           │是
                    ┌──────▼──────┐
                    │附加/罚分评估 │  只影响排序与评级
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │ 综合评级输出 │  S/A/B/C + 计划提示
                    └─────────────┘
```

**计分总式：**

```text
最终分 = clamp(1, 100, 七星主分 + 质量附加(≤10) − 过热罚分)
入选硬条件 = 市场门通过 ∧ 硬过滤全过 ∧ 七星主分 ≥ 65
排序键 = 最终分 ↓，同分看首次封板更早者优先
默认输出 = Top 1–3
```

### 3.1 评估表

|---|---|---|---|---|
| 全市场涨停家数 | 涨停池数量 | **≥ 30** | _____ | ☐通过 ☐弱市空仓 |

### 3.2 判定规则

- **弱市空仓**：当日停止个股评估，评估结论写「市场门未过」。  
- **通过**：进入第二层。  
- 说明：市场门是环境开关，不计入个股七星分。

## 6. 第四层：质量附加与过热罚分

> 仅用于**排序与评级微调**，**不能**把未达 65 的票抬进候选池。

| 条件 | 加分 | 勾选 |

## 7. 综合评级规则

仅对「硬过滤通过且七星≥65」的标的评级：

| 评级 | 条件 | 含义 |
|---|---|---|
| **S** | 最终分 ≥ 85 且 玉衡 ≥ 16 且 未炸板 | 优先计划席位 |
| **A** | 最终分 ≥ 75 | 可进当日候选 |
| **B** | 最终分 ≥ 65 | 观察备选（池满时让位于 A/S） |
| **C** | 七星≥65 但最终分因罚分 < 65 | 谨慎；默认不进 Top3，除非池极空 |
| **否决** | 市场门/硬过滤未过，或七星 < 65 | 不进入候选 |

池内排序：最终分降序；最终分相同则首次封板更早优先；再相同则封单比更高优先。

## 11. 评估纪律

1. 凡价格、市值、换手、封板时间、涨停家数，必须来自当时可得真实数据。  
2. 缺关键数据（尤其流通市值）→ 硬过滤否决，禁止主观补分凑 65。  
3. 不得用同一变量在多个星上「改头换面」重复满分。  
4. 手册历史胜率数字不得写入评估结论当作收益保证。  
5. 评估结果是建议层；最终交易仍以候选池登记 + 预检为准。

---

## 12. 一句话标准

**弱市不做；硬过滤清场；七星满 65 才有资格；质量加分只排序，过热罚分只降权；评级服务于 Top1–3 候选，不替代 L1 风控。**
